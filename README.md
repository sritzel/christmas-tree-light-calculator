# Cone Tree Light Wrap Calculator

A single-file web calculator for spiraling a continuous string of lights around a cone-shaped
tree with even vertical spacing.

Enter the tree height, base diameter and light length. It returns the number of wraps, the
vertical spacing between wraps, and a marking guide (height and string used at each wrap).

- Height can be entered as straight-up height or measured along the slope.
- Feet/inches or meters/cm.
- Optional allowance for an unlit lead and an approximate bulb count.

Open `index.html` in any browser. No build step, server or internet connection is needed.
It can be hosted as-is, for example with GitHub Pages.
